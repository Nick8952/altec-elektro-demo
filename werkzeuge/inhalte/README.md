# Inhaltsquellen

`seiten/*.mjs` sind die redaktionellen Quellen der Demo (Markdown-ähnlich, siehe `pt.mjs`). `npm run inhalte` schreibt daraus
`data/seiten/*.json` (Portable Text) und `data/leistungen.json`. Unternehmensdaten, Navigation, Team und Partner liegen direkt als
JSON in `data/`. Alle Texte stammen von altec-elektro.ch (Stand 25.09.2026); Änderungen gegenüber der Quelle sind in
`docs/INHALTSMATRIX.md` dokumentiert.
